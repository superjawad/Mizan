# Mizan — Moroccan Salon Studio

A premium, interactive web experience for designing authentic Moroccan salons.

## Features
- Cinematic landing page with word-by-word reveal.
- Interactive 3D/2D salon configurator.
- High-quality gallery of Moroccan craft and heritage.
- Fully responsive design.

## Deployment
This project is hosted on GitHub Pages. To deploy your own version:
1. Create a new repository on GitHub.
2. Push this code to the repository.
3. Enable GitHub Pages in the repository settings.
